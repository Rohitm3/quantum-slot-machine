Clone the repo
git clone <YOUR_REPO_URL>
cd quantum-slot-machine

Install dependencies
pip install -r requirements.txt

If pip points to the wrong Python, use:
python -m pip install -r requirements.txt

Run the app
From the repo root:
streamlit run app/app.py

Stop the app
In the terminal where Streamlit is running:
Press Ctrl + C

Common issues
1) ModuleNotFoundError: No module named 'plotly'

Plotly is optional. If you want charts:

pip install plotly


(If you don’t install it, the app still runs.)

2) ModuleNotFoundError: No module named 'qiskit_aer'
pip install qiskit-aer
