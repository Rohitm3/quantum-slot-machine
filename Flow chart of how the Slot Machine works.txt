START APP (Streamlit)
   |
   v
Load UI + CSS + Sidebar controls (Bias θ, Variation %, Oracle Mode)
   |
   v
Initialize session state:
  - credits, total spins, wins
  - last reels, last message, history
   |
   v
User clicks SPIN
   |
   v
[Check credits]
  |
  +--> Not enough credits -> show "Not enough credits" message -> END
  |
  +--> Enough credits ->
          |
          v
        Place Bet (subtract 10 credits, spins +1)
          |
          v
        Choose mode:
          |
          +--> Oracle Mode ON
          |        |
          |        v
          |    Run Oracle Spin (simple 3 reels, 1 qubit each + flag)
          |        |
          |        v
          |    Measure bits -> map to 🍒/💎 -> evaluate win -> payout
          |
          +--> Oracle Mode OFF
                   |
                   v
             Run Normal Spin (3 reels, 3 qubits each = 9 qubits)
                   |
                   v
             Apply H + RY(bias) + optional entanglement + measure
                   |
                   v
             Convert bits -> symbol (🍒..7️⃣) -> evaluate win -> payout
          |
          v
Add winnings to credits (credits = credits - bet + payout)
          |
          v
Animate reels (visual spin effect)
          |
          v
Show result message (Jackpot / Double / No match)
          |
          v
Save spin to history table
          |
          v
END (Wait for next click)
